# Nuweiba Camps × ProMedia — Strategic Proposal Presentation 2026

الموقع التفاعلي الاستراتيجي المزدوج (عربي / إنجليزي) لمقترح تطوير العلامة التجارية والنمو الرقمي لمنصة **نويبع كامبس (Nuweiba Camps)** بالشراكة مع **بروميديا (ProMedia)**.

---

## 🌟 الميزات المنفذة (Key Features)

1. **دعم ثنائي اللغة كامل وبنقرة واحدة (AR / EN):**
   - تحويل فوري وديناميكي كامل لكافة النصوص، مع قلب التخطيط التلقائي (`dir="rtl"` للعربية و `dir="ltr"` للإنجليزية).
   - حفظ تفضيل اللغة في التخزين المحلي (`localStorage`).

2. **التنقل الزمني الثابت (Persistent Top Timeline Navigation):**
   - شريط ملاحة علوي ثابت يضم شعار نويبع كامبس وشعار بروميديا.
   - جدول زمني تفاعلي يتابع موقع التمرير (`Scroll Spy`) ويبرز القسم النشط مع شريط تقدم علوي دقيق.
   - زر مباشر للانتقال إلى الموقع الرسمي لنويبع كامبس (`nuweibacamps.com`).
   - قائمة سريعة متجاوبة ومناسبة للهواتف الذكية.

3. **الأقسام الـ 16 الكاملة للمقترح الاستراتيجي:**
   - **القسم 01:** الغلاف والرؤية الاستراتيجية 2026.
   - **القسم 02:** قراءة العلامة التجارية ومنصة نويبع كامبس (مع توثيق تاريخ 2009 كمعطى مرجعي).
   - **القسم 03:** التحدي مقابل الفرصة (جدول مقارنة استراتيجي مبني على الفرص التطويرية).
   - **القسم 04:** شرائح الجمهور المستهدف (مبدل تفاعلي بين 5 شرائح مع المحفزات والدعوات المقترحة).
   - **القسم 05:** نموذج بروميديا للنمو (4 محركات: الاستكشاف، التواصل، المعايشة، والتحويل).
   - **القسم 06:** كبار المؤثرين (Mega Influencers) بترتيبهم الدقيق: الزوزات / كعب داير (ملف الأولوية مع مشغل الفيديو الأصلي)، أحمد بدوي، كيرو، كريم السيد، بسنت نور الدين.
   - **القسم 07:** شبكة المؤثرين المصغرين (Mini Influencers) بالمجلدات المكتشفة محلياً (استديوهات شد الحيل، إسراء صبحي، ساره طارق، مايا، محمود زيزو) مع الروابط المرجعية الستة الأصلية.
   - **القسم 08:** إنتاج محتوى المستخدمين المقترح (UGC) بـ 4 مفاهيم إبداعية متميزة.
   - **القسم 09:** سلاسل محتوى فريق المنصة الإرشادي (EGC) مع تفريقها التام عن UGC.
   - **القسم 10:** ركائز المحتوى الخمس (Content Pillars).
   - **القسم 11:** استراتيجية الإعلانات الممولة ومسار التحويل (4 مراحل تشغيلية).
   - **القسم 12:** فحص وتطوير التجربة الرقمية ومسار الحجز بالمنصة.
   - **القسم 13:** منظومة مؤشرات قياس الأداء (KPI Framework) لقنوات التسويق الست.
   - **القسم 14:** خارطة طريق الـ 90 يوماً (خطة مرحلية مقسمة على 3 أشهر).
   - **القسم 15:** لوحة المراجع البصرية، ومعرض المخيمات الرسمية، وقائمة المخرجات الاستراتيجية.
   - **القسم 16:** لماذا بروميديا؟ (شريك استراتيجي واحد. أربعة محركات نمو. اتجاه واحد نحو الريادة).

4. **معرض الأصول ومكتبة الوسائط:**
   - استخدام 73 ملفاً أصلياً تم فحصها ونسخها من المجلد المحلي `D:\mhare3\pro\نويبع`.
   - مشغل فيديو داخلي لمقطع فيديو كعب داير في سيناء (`kaab_1.mp4`).
   - نافذة معاينة مكبرة (Lightbox Modal) لجميع الصور ولقطات الحسابات.
